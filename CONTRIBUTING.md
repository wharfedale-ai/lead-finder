# Contributing

Issues and pull requests are welcome.

- **Found a bug or have an idea?** Open an issue. Say what you did, what you expected and what happened. Please never paste API keys, real lead lists or anyone's contact details.
- **Security problem?** See [SECURITY.md](SECURITY.md) instead of opening an issue.
- **Pull requests:** keep them small and focused. Run `npm test` before you open one; for interface changes also run `npm run test:ui`. Use synthetic data only (for example `example.com` or `.test` addresses and Ofcom drama numbers such as `07700 900123`).
- Keep the house rules: no automatic sending, `127.0.0.1` only, no telemetry, and no new dependency without a good reason.

By contributing you agree your work is released under the [MIT licence](LICENSE).
